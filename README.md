## What is Arc Wallet?

Arc Wallet is an enterprise-grade, self-custodial wallet built on **Circle Modular Wallet SDK**. Designed for businesses and institutions that require institutional security without the complexity of traditional wallets.

**No seed phrases. No private key management. Just passkey authentication.**

---

## Key Features

### Passkey Authentication
Sign transactions with Face ID, Touch ID, or device PIN. Your keys never leave your device's secure enclave.

### Enterprise Multi-Sig
Weighted signature thresholds for treasury management. CEO, CFO, CTO can have different approval weights using Circle's ERC-6900 WeightedWebauthnMultisigPlugin.

### Cross-Chain Bridge
Native USDC bridging between Arc Network and Ethereum via Circle CCTP V2. No wrapped tokens, instant transfers.

### Gas Sponsorship
Pay transaction fees with USDC. No need to hold native tokens for gas.

### Smart Contract Accounts
ERC-4337 compliant accounts with modular plugin architecture (ERC-6900).
