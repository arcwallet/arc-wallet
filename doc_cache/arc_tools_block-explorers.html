Tools

Block Explorers

Block explorers let you view, verify, and analyze transactions, addresses, contracts, and other onchain data on Arc. They provide developer and user interfaces for querying block details, inspecting smart contract interactions, and tracking USDC-based fee activity.

​
Providers

ProviderDescription
BlockscoutOpen-source explorer offering contract verification, token tracking, and API endpoints for custom integrations. A Blockscout explorer is available for Arc Testnet.
Arc’s explorers are continuously expanding: developers can use standard Etherscan-compatible APIs to query data and verify contracts seamlessly.
