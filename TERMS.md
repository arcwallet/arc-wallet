## 2. Description of Service

Arc Wallet is a self-custodial cryptocurrency wallet SDK that provides:

- **Passkey Authentication**: WebAuthn-based authentication without seed phrases
- **Wallet Management**: Create, manage, and secure cryptocurrency wallets
- **Transaction Signing**: Sign and send blockchain transactions
- **Cross-Chain Transfers**: USDC transfers via Circle CCTP
- **Account Abstraction**: ERC-4337 smart account support with gasless transactions
- **Batch Operations**: Execute multiple transactions in one operation
